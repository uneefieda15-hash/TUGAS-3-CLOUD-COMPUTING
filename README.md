## Analisis Singkat Pemilihan Tipe Instance & Region
- **Tipe Instance / Spesifikasi:** Menggunakan mesin virtual di VirtualBox dengan alokasi resource yang disesuaikan untuk menjalankan sistem operasi, pengujian jaringan lokal, dan akses jarak jauh SSH secara stabil tanpa membebani perangkat utama.
- **Region / Konfigurasi Jaringan:** Menggunakan konfigurasi jaringan lokal (`Bridged Adapter`) agar mesin virtual berada pada jaringan yang sama dengan perangkat pengujian sehingga koneksi berjalan langsung dan memiliki latensi rendah.
